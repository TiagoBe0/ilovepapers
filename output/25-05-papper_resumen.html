Chemiscope 1.0: Visualizacion Interactiva de Estructuras y Propiedades Atomisticas

Chemiscope 1.0 es una herramienta de visualizacion interactiva para explorar grandes conjuntos de estructuras atomisticas junto con sus propiedades fisicoquimicas. La version 1.0 introduce soporte multi-entorno, una API Python que acepta datos de ASE, MDAnalysis, stk y Chemfiles, y backends nuevos: widget Jupyter, aplicacion Streamlit, integracion en Sphinx y app web standalone en chemiscope.org.

Que Es Chemiscope

Chemiscope es un visualizador interactivo que vincula un mapa de espacio latente (por ejemplo, una proyeccion 2D de descriptores quimicos) con la estructura atomistica 3D correspondiente. Cuando el usuario hace clic en un punto del mapa, Chemiscope muestra la estructura asociada en el visor 3D. Esto es muy util para analizar datasets grandes de estructuras, como los generados por aprendizaje automatico o busqueda de materiales.

La version 1.0 extiende la herramienta original con soporte para multiples entornos quimicos por estructura, lo que permite analizar propiedades locales (por atomo o por enlace) ademas de las globales (por estructura).

Arquitectura y Backends

API Python

Acepta estructuras desde ASE, MDAnalysis, stk y Chemfiles. El usuario pasa las estructuras, propiedades y configuraciones de visualizacion al objeto Python y elige el backend de salida.

Widget Jupyter

Se renderiza directamente en un notebook. Permite exploracion interactiva sin salir del entorno de analisis. Ideal para explorar datasets durante el desarrollo de modelos ML de potenciales interatomicos.

Streamlit

Permite embeber Chemiscope en aplicaciones web interactivas construidas con Streamlit. Util para crear paneles de exploracion de materiales sin necesidad de infraestructura compleja.

Sphinx / Web

Puede integrarse en documentacion tecnica generada con Sphinx, y tambien exportarse para la aplicacion web standalone en chemiscope.org, accesible desde cualquier navegador.

Soporte Multi-Entorno

La novedad central de la version 1.0 es el soporte multi-entorno: cada estructura puede tener multiples entornos asociados, donde cada entorno corresponde a la vecindad local de un atomo o un fragmento de la estructura. Esto permite colorear cada entorno segun propiedades locales calculadas (carga, energia por atomo, tipo de hibridacion, etc.) y explorar simultaneamente como se distribuyen esas propiedades dentro de cada estructura y entre estructuras distintas.

Este tipo de visualizacion es especialmente relevante para analizar potenciales de aprendizaje automatico (MLPs), donde las energias y fuerzas son propiedades locales definidas por entorno atomico.

Caso De Uso: Dataset MD22

El paper demuestra Chemiscope con 50.000 estructuras aleatorias del dataset MD22, proyectadas al espacio latente reducido usando el descriptor PET-MAD via chemiscope.explore. Los autores muestran cuatro capacidades:

Vista global del dataset

El mapa 2D muestra todos los puntos del dataset coloreados segun una propiedad. El usuario puede identificar clusters de estructuras similares de un vistazo.

Renderizado adaptativo (LOD)

Al hacer zoom, el sistema aumenta el nivel de detalle de los puntos en la zona ampliada, evitando saturacion visual en datasets grandes.

Coloreado selectivo

La vista 3D puede colorear atomos segun cualquier propiedad, en el ejemplo segun la energia cohesiva del entorno.

Fuerzas como flechas

La funcionalidad shape permite visualizar vectores por atomo (fuerzas, desplazamientos, gradientes) como flechas 3D sobre la estructura.

Por Que Importa Este Paper

Exploracion de datasets grandes de ML: A medida que los potenciales de aprendizaje automatico se entrenan con millones de configuraciones, herramientas como Chemiscope permiten identificar problemas de cobertura, outliers y sesgos del conjunto de entrenamiento de forma visual e intuitiva.

Reproducibilidad y publicacion: La integracion con Sphinx y la app web permite publicar visualizaciones interactivas junto a los papers, haciendo los datasets explorables sin necesidad de instalar software.

Interfaz estandarizada: Al soportar ASE, MDAnalysis, stk y Chemfiles, Chemiscope se conecta con la mayoria de los flujos de trabajo de simulacion atomistica existentes sin conversion manual de formatos.

Resumen Final

Chemiscope 1.0 es un avance de infraestructura para la ciencia de materiales computacional. No propone un nuevo metodo de simulacion ni un nuevo descriptor, sino que resuelve el problema de exploracion e interpretacion de datasets grandes de estructuras y propiedades. La idea central es simple: vincular el mapa de espacio latente con la estructura 3D en tiempo real, de modo que navegar el dataset sea tan intuitivo como explorar un mapa geografico. El soporte multi-entorno abre la puerta a analizar propiedades locales (por atomo) ademas de globales, lo que es especialmente util en el contexto de MLPs donde toda la fisica es local.
